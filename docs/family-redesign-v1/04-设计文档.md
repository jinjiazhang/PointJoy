# 积乐圈家庭版 · 设计文档

版本：1.0 · 2026-09-19 · 交付对象：视觉设计、前端、交互、验收。

本文是可实施的视觉规范与设计交付要求；业务与页面行为分别以 [00-规则基线](./00-规则基线.md)、[03-交互文档](./03-交互文档.md) 为准。附带 [设计预览.html](./设计预览.html) 可双击打开，展示核心布局与交互。本次为重建文档和概念预览，没有修改或发布生产小程序。

## 1. 设计方向

产品应像一份被认真对待的家庭约定。家长页面优先呈现待处理事实，孩子页面优先呈现具体行动与得到的回应。整体使用温暖的纸色背景、深绿文字和少量黄色，表达平静、清晰的积极感；不用商城促销、排行榜、金币爆炸或惩罚警报驱动孩子。

家长与孩子共用色板、任务图标和订单语言，以降低切换理解成本；家长布局更重视信息密度与筛选，孩子布局更重视一句话要求、较大触达区和每卡一个主动作。奖励可以是游戏时间、食品、物品、共同体验，不能让视觉使某类消费成为唯一目标。

设计验收的核心不是“可爱”：孩子能分清提交和得分、申请和批准；家长能分清批准和兑现；任一端能看懂可用和预留；首次登录不能绕过头像昵称；照片失败不会丢文字；共用设备和独立账号不会互相冒充。

## 2. 页面与原型组织

完整页面编号 S01—S04、P01—P16、C01—C06 见交互文档，设计文件沿用相同名称。一个编号包含多个子页时加后缀，例如 `S01a-微信登录`、`S01b-强制资料`、`P12c-账号绑定`、`C06c-DIRECT个人隐私`；子页有独立画板和恢复定位，不意味着一个画板包含全部表单。

设计文件建议分为五个页面：`00-基础变量`、`01-组件与状态`、`02-共享与身份`、`03-家长端`、`04-孩子端`。另放交互连线和导出清单，不把关键异常仅写在备注里。画板注明角色、状态、入口、后台依赖、服务端时间样例和对应验收编号。

附带 HTML 覆盖 P01/P02/P03/P04/P07/P10/P11、C01/C02/C03/C04/C06，加 S01 登录与资料、S03 PIN 面板以及 C05 订单摘要。其余 P0 页面不能因未做可点击稿而省略。预览中的演示身份、上传进度、初始积分、固定日期和公开 PIN 都是说明用模拟值，不能拿来实现鉴权、时间或账务。

## 3. 设计变量（Design Tokens）

### 3.1 色彩

所有颜色以语义变量使用，不在业务组件散落十六进制值。下列对比值按 sRGB 相对亮度计算并四舍五入；它们是本设计配色的计算结果。文字目标至少 4.5:1，大号文字至少 3:1，控件轮廓与焦点至少 3:1；上线时需验收最终实渲颜色，不能只查源代码。

| 变量 | 色值 | 使用位置 | 指定组合对比 |
| --- | --- | --- | --- |
| `color.bg.canvas` | `#F7F5EF` | 全局纸色底 | 不直接作为状态文字 |
| `color.bg.surface` | `#FFFFFF` | 表单、卡片、弹层 | 白底 |
| `color.text.primary` | `#213C36` | 标题、主要正文、数值 | 白底 11.90:1 |
| `color.text.secondary` | `#52645E` | 时间、说明、帮助 | 白底 6.28:1 |
| `color.action.primary` | `#176B5B` | 主按钮、选中导航、文本链接 | 白字 6.38:1 |
| `color.action.pressed` | `#105244` | 按下的主按钮 | 配白字，按压不改变布局 |
| `color.action.soft` | `#E9F2E9` | 轻选中块、无风险提示 | 配深绿文字 |
| `color.accent.sun` | `#F7D46A` | 心愿插画背景、点缀 | 配主文字 8.26:1；禁用白字 |
| `color.success.text/bg` | `#246B46 / #EAF5EC` | 已通过、已兑现 | 5.75:1，附图标和文字 |
| `color.warning.text/bg` | `#815700 / #FFF4D3` | 待审核、待批准、需补充 | 5.80:1；不用于羞辱未完成 |
| `color.danger.text/bg` | `#A43C3C / #FFF0ED` | 字段错误、撤销确认 | 5.76:1，附错误描述 |
| `color.border.decorative` | `#DCE5DC` | 非必要卡片分隔 | 不单独承担输入边界识别 |
| `color.border.control` | `#798F85` | 输入、未选中复选框边界 | 白底 3.45:1 |
| `color.focus` | `#176B5B` | 2—3 px 外焦点环 | 与按钮/底色保持可见间隙 |
| `color.disabled.bg/text` | `#E7EBE5 / #68766E` | 禁用动作 | 必须附禁用原因，不靠透明度表达 |
| `color.overlay` | `#173D36` @ 35% | 模态遮罩 | 背景不可继续点击或读作当前表单 |

不以红/绿区分唯一状态：待审核需文字，已完成带勾和文字，需补充附原因。金额和积分不使用“跌涨”颜色语言；撤销/退款以类别区分。冻结的预留积分使用中性标签，不画成负债。

### 3.2 字体与排版

使用系统中文字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`；P0 不下载外部中文字体。数字使用等宽数字特性 `tabular-nums`（平台支持时），保持余额位数变化不跳动。

| 变量 | 字号 / 行高 / 字重 | 适用 |
| --- | --- | --- |
| `type.display` | 32 / 40 / 700 | 余额主数字；最多一个主数字层级 |
| `type.title.page` | 26 / 34 / 700 | 每页主标题 |
| `type.title.section` | 20 / 28 / 650 | 任务/奖励/待办分区 |
| `type.title.card` | 17 / 25 / 600 | 卡片标题，可两行 |
| `type.body` | 16 / 25 / 400 | 家长正文、表单与详情 |
| `type.body.child` | 18 / 28 / 400 | 孩子主任务说明、主指令 |
| `type.body.secondary` | 14 / 22 / 400 | 时间、辅助说明、保存期限 |
| `type.label` | 13 / 19 / 600 | 类型与状态标签 |
| `type.caption` | 12 / 18 / 400 | 非关键文档标注；不用于孩子核心操作 |
| `type.button` | 家长 16 / 24 / 600；孩子 18 / 26 / 600 | 主按钮 |
| `type.tab` | 12 / 18 / 600 | 底部导航，有图标及可访问文本 |

标题最多两行，详情正文完整换行；列表长标题允许两行截断并可进入完整详情。昵称最多 24 字，头像同行可换两行，但确认页必须呈现完整昵称以便区分同名孩子。不要强制极细字重，不给中文正文加字间距。数字、单位不可拆到两行；价格写「30 积分」而非「¥30」。

### 3.4 动效与层级

按压反馈 100 ms，组件显隐/状态过渡 160—220 ms，局部确认动画最多 600 ms；积分到账仅在服务端成功后做一次轻量数值变化和勾选反馈。无强制音效，无循环抖动，无随机奖励/抽奖表现。系统减弱动态效果时立即切换状态，不动画进度条、不做视差。

层级固定：页面 0，黏性区 10，底部导航 20，遮罩 100，模态 110，操作状态播报 120。模态打开后背景不可操作，焦点进入标题/首个输入，关闭回原触发控件。Toast 只承载短暂反馈；错误原因、恢复入口、审批到期必须在页面中持久呈现。

## 4. 页面布局规范

### 4.1 家长主页面

顶部身份栏（家庭名、本人角色、切换入口）→ 页面标题和日期/说明 → 核心任务区 → 次级内容 → 底部四导航。P01 首屏展示待审核、待批准、待兑现三项，最小宽度下可排三等份，但文字至少两行且触达面积足够。计数 0 仍显示分类，避免用户误以为兑现待办不存在。

P03 和 P07 在页标题下用二分段控件区分内容；筛选位于分段下方，筛选条件可见，不能只留一个没有当前值的漏斗图标。家长没有“我的积分”卡；只在指定孩子卡和账户页显示积分。

### 4.2 孩子主页面

顶部孩子头像昵称+会话来源，DELEGATED 右侧为家长入口，DIRECT 为账号设置。中间一次只安排一个主要视觉焦点：C01 今天任务、C03 当前心愿、C06 本人记录。今日任务一列，不使用轮播藏任务；奖励库可以两列，但标题/价格不能截断到不可理解。

卡片动作使用动词「我完成了」「去补充」「查看记录」，不要只用箭头或一个“GO”。今日没有安排时给休息/商量提示，不用失败图形。已完成可以折叠，不在用户刚提交后跳到页面顶部造成迷失。

### 4.3 详情、表单与确认

详情导航为返回+标题，省去底部主导航；内容区先呈现对象与状态，再说明，再表单或时间线，末尾出现主动作。重要确认在用户提交前呈现孩子、对象、数值、后果，不需要连续弹两次相同确认。

键盘弹出时，当前字段和提交区可滚动露出，不把页面整体压成固定高度；数字字段显示固定单位，姓名/原因使用文本键盘。输入错误显示在字段下且不改变其他字段值，自动聚焦首个错误。文本编辑页返回时提供继续编辑与放弃，未确认业务操作则进入恢复流程，不用“放弃”删除服务器结果。

### 4.4 屏幕适配

- 主设计基准宽 390，至少验证 320、360、375、390、430、768 逻辑 px；典型手机为 360—430。
- 手机内容单列；宽屏最大内容宽 720，表单最大宽 560，列表可双列但阅读和操作顺序不变。不要复制桌面侧栏成为小程序新导航。
- 顶部使用系统状态栏及微信胶囊实测尺寸，标题不进入胶囊区域；底部预留安全区和完整按钮高度。
- 200% 文本缩放允许卡片纵向扩展，双列奖励变单列，三列待办可转纵向或横向可滚动区域，并提供可见滚动提示。
- 列表末尾留出底部导航/固定操作区总高度再加 16，最后一个按钮不可被遮挡。键盘、横屏或低高度屏幕下模态可滚动。

## 5. 组件与状态规范

| 组件 | 结构和状态 | 必须交付的行为/画板 |
| --- | --- | --- |
| `IdentityBar` | 家庭/孩子身份、头像、角色、当前来源 | 家长、DIRECT、DELEGATED、加载、失效；DIRECT 无 PIN 升权按钮 |
| `BottomNav` | 图标+中文名称，当前页高亮 | 家长四项、孩子三项；选中、键盘焦点、安全区 |
| `TaskCard` | 类型、名称、要求、积分、状态、唯一主动作 | OPEN、SUBMITTED、NEEDS_CHANGES、APPROVED、EXEMPTED、REVOKED、未开始/逾期派生态 |
| `TodoCard` | 类别、计数、解释、入口 | 0、有待办、加载、失败；待兑现无自动消失 |

| `WishCard` | 奖励、一份权益、进度、还差积分 | 未设、积攒中、已攒够、已下架；不用预留积分计算进度 |
| `RewardCard` | 内置插画、名称、价格、状态 | 可申请、积分不足、售罄、周限额、不可适用、下架；有原因说明 |
| `OrderStatus` | 状态文字、解释、时间线、后果 | 待批准、READY、FULFILLED、拒绝、取消、过期、释放处理中 |
| `AvatarUploader` | 必填标识、图像/占位、选择、预览裁剪 | 未选、权限拒绝、上传中、处理中、可用、失败、保存未明；占位不可通过资料关卡 |
| `EvidenceUploader` | 0—3缩略图、相机/相册、期限说明 | 每图上传/处理/READY/失败/已过期；失败重试/移除，所有保留图READY才可提交 |
| `PrivateImageViewer` | 大图、当前序号、关闭、来源说明 | 加载、成功、URL失效重新鉴权、无权、180天清理；不公开分享到第三方 |
| `InputWithUnit` | 标题、数字输入、单位、范围说明 | 空、合法、未达标草稿、超上限、非整数、只读历史 |
| `ReasonForm` | 原动作/对象、原因输入、确定后果 | 必填、200字、空白错误、保存中、状态冲突 |
| `SegmentFilter` | 类别分段+孩子/日期/状态筛选 | 默认、选中、无结果、重置；切家庭清空原条件 |
| `Timeline` | 事件、操作人、时间、原因与照片版本 | 初次提交、多次退回、代录、通过、撤销；不覆盖旧事实 |
| `LedgerRow` | 动作、可用变化、预留变化、来源、结果 | 赚取、预留、批准消费、释放、退款、撤销；标签和数字都要准确 |
| `PinPanel` | 6位密码、错误、恢复说明、取消 | 输入、错误、服务端限流倒计时、验证中、恢复码、无恢复码支持入口 |
| `ProfileGate` | 登录身份、必填头像/昵称、提交 | 半完成、已完整、媒体失败、资料保存未明、深链回跳 |
| `InviteCard` | 成人/孩子绑定用途、发起人、到期、目标 | 待申请、待审核、通过、拒绝、撤回、过期、撤销、已使用 |
| `ArchivePrecheck` | 待处理阻塞项、跳转、只读账本说明 | 有待办禁止确认、非零余额需确认、通过、权限失效 |
| `DataRequest` | 范围、申请状态、时间、请求号 | 个人/家庭分离、提交、处理中、导出可取/已过期、删除完成/失败 |
| `OperationRecovery` | 原动作、对象、时间、结果状态、查询 | 查询中、原成功、明确失败、仍未知、重登录；无新建同意图按钮 |

禁用动作仍应显示原因。尺寸不足时用多行文本和自动高度，不把提示缩到 10 px。按钮文案最多约 10 个中文字符时优先保持单行；包含完整金额的取消按钮可自动换行，不省略金额。

## 6. 关键页面线框和文案

以下是结构示意，间距与组件样式以变量表为准。方括号代表控件，不是生产文案中的括号。

### S01b 强制资料：所有用户共用


## 8. 无障碍、可用性与儿童理解

1. 图标都有语义文本或可访问名称，图片按钮注明「查看第1张完成照片」「移除第1张照片」。装饰性插画不朗读。头像的姓名不重复读三次。
2. 屏幕阅读顺序为身份→标题→当前状态→内容→操作。状态更新只播报关键结果一次；上传进度不能每1%持续打断，按阶段播报即可。
3. PIN 密码以密码字段输入，支持粘贴但不明文朗读；恢复码有安全保存说明，不能让孩子页随时查看。DIRECT 界面不存在一个会调用成人升权的隐藏快捷键。
4. 焦点环可见；弹层打开时焦点约束在当前弹层，关闭回触发元素。错误聚焦首字段并保留输入，不要求用户重新填写整张表单。
5. 每个主要动作至少44×44，孩子主要按钮52高。图片移除图标视觉可小，但透明触达区必须达到44，且不能覆盖相邻图点击区域。
6. 颜色不独立表达成功、失败、是否可操作。高对比/灰度下仍能区分类型和状态；文本缩放200%无关键截断。进入系统减弱动态后取消非必要动画。
7. 时间标签写「9月20日18:00前补充」，不只写“剩24小时”；边界以服务端为准，刷新时差异可被解释。关键价格和后果不依赖听声音才能知道。
8. 孩子主界面使用具体动词与短句；不把“幂等”“事务”“库存占用”“LOCKED”这类实现词展示成日常提示。开发/演示说明可呈现技术名，生产儿童界面用“共用家长设备”“自己的微信”等。
9. 食品图标不出现“必须吃”“多吃才能开心”等引导；任务目标和奖励约定由家长决定，不在模板中按年龄给出强制运动量。

## 9. 图片、图标与资产交付

### 9.1 系统资产

P0 计划和奖励使用内置图标/插画：通用活动、跳绳、跑步、阅读、整理、创作、游戏时间、冰淇淋、薯条、物品、出游/体验、心愿、休息、成功、空态。图标使用24×24网格、约2 px描边、圆端点；一个图标不混用细描边与重填充。提供 SVG 源文件以及小程序可用的 PNG 2×/3×；颜色可映射语义变量。

插画遵守128/256/512尺寸档位，保持安全边界≥8%；背景透明或指定语义底色。不用网络热链和来源不明儿童照片。交付命名如 `activity-rope.svg`、`reward-game.png`，提供作者/授权来源与使用范围清单。附带HTML中的图标和示意头像/照片由内联SVG绘制，仅用于演示。

### 9.2 用户上传资产

账号头像与孩子档案头像是**用户主动上传且服务端验证的文件**，不是系统内置插画选择器。占位头像可用于资料加载或上传前，但不能满足强制资料完整条件。上传者可自行选择插画文件，不要求真人；设计稿不要将“真人自拍”作为唯一素材。

完成照片为0—3张、每张原文件≤10MiB且≤4,000万像素，JPEG/PNG/WebP；服务端去EXIF/GPS并重编码JPEG，最长边1600；头像输出512方形JPEG。客户端压缩与预览只是体验辅助，不能宣称前端已满足服务端安全校验。上传反馈、失败重试与清理期限都要在设计图中覆盖。

图片从私有存储鉴权后获取短时可读地址，设计和开发不得在公共CSS、配置、日志或分享图里嵌入孩子图片。切家庭/孩子、退出、解绑/移除失权时清理对应缓存；私有链接失效需重新鉴权，不显示旧图无限续读。

完成照片以首次正式提交起180天清理，重复引用不续期；未正式提交照片（含服务端草稿引用）上传后24小时清理，草稿提醒重选。当前有效账号/孩子头像不套完成照片的180天/24小时规则。照片到期保留文本、账本事实与清理说明。家庭/个人删除覆盖范围按技术文档。

## 10. 设计验证与实施限制

视觉验收须覆盖：微信胶囊和底部安全区、320窄屏、200%文字、键盘挡住提交、多行昵称和200字原因、长奖励名、余额0/未知/大数、奖励双列改为单列、三图上传失败与到期、已归档只读、DIRECT与DELEGATED不同身份入口。

交互可用性走查至少包括：家长单独完成一次代录和自己的审核；孩子知道提交后尚未得分；孩子申请后能找回订单；家长批准后没有误认为已兑现；误点取消能读到返还数和原因；网络未知时不会另建重复订单；照片失败可删掉无图提交；DIRECT不能借家长PIN访问其他孩子。

建议在家长陪同下让少量目标年龄儿童完成脚本任务，仅记录理解障碍和点击问题，不从小样本宣称行为或教育效果。功能模板、文案和示意图都可据此调整，但未经正式变更不能改变积分、审核、身份、照片权限及时间规则。

HTML验证仅覆盖演示的浏览器布局和本地状态转移。真实小程序仍须实现并验证微信登录、强制服务端资料关卡、私有媒体处理、账号绑定、服务器PIN与恢复码、权限隔离、幂等事务、时间调度与隐私数据请求。演示中可见“填入演示资料”“恢复初始演示”等属于文档工具，不得进入生产页面。
