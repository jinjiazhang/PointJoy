## 1. 工程结构与环境约定

当前使用 uni-app + Vue 3 + TypeScript + Pinia，API 为 Fastify 5 + TypeScript + Zod + pg + PostgreSQL 16。worker 与 API 共用工程。依赖由 package.json、package-lock.json 与运行环境配置锁定。

```text
apps/
  mini/src/
    pages/{auth,guardian,child}/ # 共享、家长和孩子页面
    components/                   # 导航、图标、媒体上传等
    features/                     # 各业务 Screen 组件
    stores/                       # 会话与上下文
    services/                     # API、凭据与操作恢复
    design/                       # 主题
  api/
    src/{identity,family,media,privacy}/
    src/domain/                   # 计划、审核、积分、奖励、统计
    src/common/                   # 事务、幂等、审计与恢复
    src/worker.ts                 # 后台任务入口
    migrations/                   # SQL 迁移
packages/contracts/               # OpenAPI 契约
tests/                            # 服务端测试
ops/                              # 部署与运行手册
```

API DTO 与数据库模型分开，数据库查询结果经响应契约转换后返回前端。服务端使用 Zod 执行运行时校验。对未知字段拒绝，字符串去首尾空白按 Unicode 字符计数，不按 UTF-8 字节截中文。所有文本按纯文本展示。实际注册接口见 [OpenAPI](../packages/contracts/openapi.json)。

环境变量样例只表达配置名，真实秘密由部署密钥服务注入，不进入仓库、小程序包、日志或文档：


## 2. HTTP、时间、DTO 和幂等公共契约

根路径 `/api/v1`，HTTPS、JSON UTF-8、camelCase、枚举大写、ID 为 UUID。认证 `Authorization: Bearer <accessToken>`。状态和金额均服务器计算；任何 actorUserId、actorRole、familyRole、openid、balanceAfter 等客户端伪造字段直接拒绝。

时间戳为 UTC ISO 8601 毫秒格式，业务日期 `YYYY-MM-DD`，固定 Asia/Shanghai；星期用整数 1–7（周一到周日）。截止使用右开区间。COUNT 为整次/个，DURATION 为整分钟，DISTANCE 为整米，TIME 奖励为整分钟；前端可显示公里，但提交须无损换算为整米。积分/库存/版本由数据库 bigint 承载，输出 JSON number 前检查 `Number.isSafeInteger`；超安全范围的历史累计统计使用显式 `amountText` 十进制字符串，不能静默舍入。

成功创建 201；查询/修改/动作 200；异步处理 202。统一响应：

```json
{"data":{"id":"c6463be1-7287-4c01-807d-cedac64f41f2"},"requestId":"f7917ce4-5c6d-4a08-8890-56b3e9387601","serverTime":"2026-09-19T03:00:00.000Z"}
```

列表 `data={items,nextCursor,hasMore}`；默认 limit=20，范围 1–100，opaque cursor 绑定家庭、孩子、筛选与排序。账本按 accountVersion DESC，其余默认 `(createdAt DESC,id DESC)`；变更筛选重置 cursor。需要总量的待办/统计由专门聚合给出，不能用当前页长度估计。

```json
{"error":{"code":"INSUFFICIENT_POINTS","message":"可用积分不足","details":{"required":50,"availablePoints":30,"heldPoints":20}},"requestId":"f7917ce4-5c6d-4a08-8890-56b3e9387601","serverTime":"2026-09-19T03:00:00.000Z"}
```

所有业务 POST/PUT/PATCH/DELETE 要求 `Idempotency-Key: UUID`；创建一次意图即保存 key 与规范请求，响应前重复点击复用。PATCH 与已有资源动作要求 expectedVersion，库存调整另用 expectedStockVersion；缺省字段不变，显式 null 清空可空值。只读 POST 预览、登录/刷新/PIN/读取媒体凭证是专门协议，不使用普通业务响应缓存；媒体完成操作本身幂等。

幂等唯一范围为 `(actorScope,method+concretePath,key)`，actorScope 包括真实 userId、mode、familyId、childId、DIRECT/DELEGATED 来源。服务端当前授权先于重放查询，同键不同内容返回 409；成功同键重放原 HTTP 结果并附 `Idempotency-Replayed: true`，requestId/serverTime 刷新。余额是原操作时结果，重放后另读现值。

网络未明时先查询原操作；查询无已提交结果仍只重试同键同内容，不换 key。客户端保存待确认记录到本地，按账号/作用域隔离；切换模式后不能读取家长待确认响应，回到合法家长上下文再恢复。普通变更写事务和幂等结果同提交，认证凭据不写入普通操作记录。

## 4. P0 接口完整清单

下文 `F` 表示 `/families/{familyId}`，`c/p/o/r/i/a/m` 分别是路径中的孩子/计划/实例/奖励/订单/申请/媒体 UUID，实际 OpenAPI 必须展开完整路径。权限缩写：A=本人登录账号，G=本家庭有效家长，O=负责人，C=该孩子 DIRECT 或 DELEGATED，D=仅 DIRECT 的本人账号能力。所有 C 请求 childId 必须等于会话绑定值；G 可为指定孩子代办。归档对象仅允许声明的只读与隐私操作。

### 4.1 登录、强制资料、PIN 与上下文（S01–S04）

| 方法与路径 | 权限 | 请求 | 返回/约束 |
|---|---|---|---|
| POST `/auth/wechat/login` | 微信 code | `{code,loginAttemptId}` | SessionTokens + SessionView；新账号 PROFILE_ONLY，设 PIN 的已有账号 LOCKED；code 单次，不把 appSecret 放客户端 |
| POST `/auth/refresh` | refreshToken | `{refreshToken,refreshAttemptId}` | 轮换 SessionTokens；不得改变模式/来源/作用域 |
| POST `/auth/logout` | A/G/C/LOCKED | 无 | `{loggedOut:true}`；撤销当前会话 |
| GET `/auth/session` | 当前会话 | 无 | SessionView + `{profileRequired,pinRequired}`，不夹带家庭数据 |
| GET `/public/privacy` | 公开 | 无 | `{policyVersion,content,supportContact,mediaRetention}` |
| GET `/me/profile` | A/G/D/PROFILE_ONLY | 无 | UserProfile；DELEGATED 拒绝 |
| PUT `/me/profile` | A/G/D/PROFILE_ONLY | `{displayName,avatarMediaId,privacyVersion,expectedVersion}` | `{profile:UserProfile,session:SessionView}`；首次头像READY+昵称+同意原子置完成，同事务将当前PROFILE_ONLY会话mode改为ACCOUNT；普通响应不含新token |
| GET `/me/contexts` | A/G/D，资料完整 | 无 | AuthorizedContext[]；DELEGATED/PROFILE_ONLY/LOCKED 不可访问 |
| POST `/auth/context` | A/G/D，资料完整 | `{contextId}` | 新作用域会话；只取本人现有 FamilyPrincipal，不从客户端角色授予 |
| POST `/auth/pin/enroll` | G且未设 PIN | `{pin,confirmationPin}` | 一次显示 `{enrollmentId,recoveryCode,expiresAt}`，仅存哈希；成功确认前不进入孩子模式 |
| POST `/auth/pin/enroll/confirm` | G | `{enrollmentId,recoverySaved:true}` | `{pinEnabled:true}`；确认保存恢复码 |
| POST `/auth/pin/unlock` | LOCKED | `{pin,targetContextId?}` | 新 ACCOUNT/GUARDIAN token，仍检查资料与真实关系 |
| POST `/auth/pin/change` | G | `{oldPin,newPin,confirmationPin}` | 安全版本更新、撤销旧会话、返回新 LOCKED 会话 |
| POST `/auth/pin/recover` | LOCKED | `{newWechatCode,recoveryCode,newPin,confirmationPin,recoveryAttemptId}` | 一次新恢复码+新 LOCKED 会话；所有旧会话/恢复码失效 |
| POST `/auth/child-mode` | G且PIN已设置 | `{familyId,childId}` | 撤销当前G会话，签发CHILD/DELEGATED；目标必须有效 |
| POST `/auth/child-mode/exit` | DELEGATED | `{pin}` | 撤销当前会话，签发源家长GUARDIAN；DIRECT不可调用 |
| POST `/auth/step-up` | G/O或A/D本人隐私 | `{pin? ,newWechatCode?,action}` | 一次、5分钟、绑定session/action的stepUpToken；已设PIN不能仅微信替代 |
| GET `/operations/{key}` | 原作用域 | `method,path` | `{state:SUCCEEDED,result}` 或 `{state:NOT_OBSERVED,retryWithSameKey:true}`；无权即拒绝，不泄露原响应 |

上下文切换规则：DIRECT 可切自己已绑定的其他孩子；若该 User 在另一家庭已有家长关系，切家长上下文先返回 LOCKED 并要求该 User 自己的 PIN（如已启用），不能使用另一个家长 PIN。DELEGATED 不列源家长全部上下文，只能 PIN 退出。无 PIN 的账号建新家庭会取得新家庭 OWNER，这是新家庭创建，不是升级已有家庭权限。

PIN 限流 5 次连续失败后 15 分钟；源账号、会话与来源分别限流，服务端共享计数。认证专门接口对 attemptId 实现短窗口重复请求恢复；涉及新 token/恢复码的响应仅在认证领域加密短时保留，绑定旧凭证及同次 attemptId。若无法安全恢复，走重新微信登录→LOCKED→PIN，不重用已消费恢复码无限重试。

### 4.2 头像与完成照片（S01、P06、P12、C02）

| 方法与路径 | 权限 | 请求 | 返回/约束 |
|---|---|---|---|
| POST `/media/upload-intents` | PROFILE_ONLY/A/G/D 或 C按用途 | `{purpose,filename,mime,sizeBytes,familyId?,childId?,occurrenceId?,crop?}` | `{mediaId,uploadUrl,requiredHeaders,expiresAt,maxBytes}`；上传URL仅写私有临时对象，10分钟 |
| POST `/media/{m}/finish` | 原有权上传者 | `{uploadChecksum?}` | 202 MediaAsset PROCESSING；服务端检查真实对象后排队，不接受自报READY |
| GET `/media/{m}` | 原上传者或有权关联阅读者 | 无 | MediaAsset；处理失败给换图或可重试提示 |
| POST `/media/{m}/retry-processing` | 原有权上传者 | 无 | 202；仅可重试暂时处理失败，不把非法图片重试成合法 |
| DELETE `/media/{m}` | 原有权上传者 | 无 | 仅未关联媒体可移除；关联后走照片期限/隐私处理 |
| POST `/media/{m}/read-grants` | 按媒体引用实时鉴权 | 无 | `{readUrl,expiresAt}`；本服务鉴权代理地址，默认60秒 |
| GET `/media/content/{grant}` | grant绑定会话 | 会话凭证或受约束签名会话证明 | 二进制JPEG；每次重验权限，不重定向对象桶签名URL |

USER_AVATAR 仅自己账号；CHILD_AVATAR 需要 G 和目标孩子创建/编辑权限（创建前允许由服务端生成 childDraftId）；COMPLETION_EVIDENCE 需要既定 familyId/childId/occurrenceId。DIRECT 可上传自己的头像和完成证据；DELEGATED 不可上传源家长头像。媒体上传不是完成提交，除正式提交/资料保存外不能设置业务成功状态。

原图≤10 MiB、≤4,000万像素，仅JPEG/PNG/WebP。服务器受限解码，先按EXIF方向auto-orient转正，再重编码去EXIF/GPS；头像512×512 JPEG，完成图最长边1600px JPEG。`crop` 只允许源图范围内矩形，服务器再次校验并裁正方。所有选中照片READY才可提交，最多3张；用户可删除失败项后无图提交。

读取代理通过 SDK header 携带会话或用绑定 sessionId 的短时 grant 并逐次查询有效性，选择能在微信 `<image>`/下载组件工作且不泄露 bearer token 到 URL 的实现；不得把 accessToken 直接拼进URL。失去家庭权限/解绑后下一次读取立刻拒绝，已在设备内显示的图片无法远程抹去。原图处理后删除；未关联24h清理，正式完成证据自首次提交起180d清理（重复引用不续期），当前头像保持到替换/删除。

## 5. 关键请求示例与错误码

### 5.1 先完成资料，再进入业务

```jsonc
// POST /auth/wechat/login 的 data
{"session":{"mode":"PROFILE_ONLY","profileRequired":true},"accessToken":"<redacted>","refreshToken":"<redacted>","expiresIn":900}
// PUT /me/profile：avatarMediaId 必须属于当前账号、用途 USER_AVATAR 且 READY
{"displayName":"小禾","avatarMediaId":"f4294aec-5672-472a-b07e-a3c4c2d2b040","privacyVersion":"2026-09-19-v1","expectedVersion":1}
```

`PUT /me/profile`使用专属稳定幂等范围`(userId,PROFILE_SELF,method+path,key)`，仅本人且非DELEGATED可查/重放，不因PROFILE_ONLY变ACCOUNT而改变。token只含sid等身份，授权模式从服务端会话取；资料保存事务更新会话mode，沿用当前token至正常续期，普通幂等不保存新凭据。头像处理成功但PUT超时，用原key查询此专属范围并重读`GET /me/profile`和`GET /auth/session`；只有 profileCompletedAt 已写入才能进入业务。无头像/冒用媒体ID/用途错误为明确业务错误，不由前端自行置完成。

### 5.2 有照片的活动提交

```jsonc
// POST F/occurrences/{o}/submissions，Idempotency-Key 固定本次提交
{"actualValue":120,"note":"和爸爸一起完成","mediaIds":["256f0c4d-c461-4c57-99da-99c952a4c192"],"expectedVersion":2}
// data（省略非关键字段）
{"occurrence":{"id":"3777a9c1-c7f9-439d-a9e9-50c803d5de20","status":"SUBMITTED","version":3},"submission":{"sequence":1,"submittedAt":"2026-09-19T09:00:00.000Z"}}
```

示例120是用户实际输入，不是普适运动标准。服务器读取目标及奖分快照判定达标；未达标返回 TARGET_NOT_MET，可保存草稿。照片仍PROCESSING返回 MEDIA_NOT_READY，保持原表单和图片处理状态。

### 5.3 申请与批准的积分差异

```jsonc
// 创建请求前账户 A=100，H=0；奖励价格40
{"rewardId":"d6e52b22-193f-42fc-bc93-8db232fc6c95","expectedRewardVersion":4,"expectedCostPoints":40}
// 创建成功 data 摘要
{"order":{"status":"PENDING_APPROVAL","costPointsSnapshot":40,"requestWeekStart":"2026-09-14","approvalExpiresAt":"2026-09-22T09:00:00.000Z","version":1},"account":{"availablePoints":60,"heldPoints":40,"version":8}}
// 家长批准后 data 摘要
{"order":{"status":"READY","version":2},"account":{"availablePoints":60,"heldPoints":0,"version":9}}
```

READY取消退40到A，得到100/0；PENDING取消释放预留，也得到100/0，但流水类型不同。FULFILLED仅更新订单，不改账户版本。上述示例省略ID字段便于说明，实际API必须返回完整DTO。

## 6. 前端状态、照片与网络恢复

应用启动先恢复 session→查服务端模式/资料门→查本人contexts或原合法作用域，再导航。不能从本地 `isParent`、缓存roles或分享链接推断权限。DELEGATED切入/退出清除源上下文的数据、图片临时文件及query cache；缓存键至少包含 userId、mode/source、familyId、childId、筛选。

前端 store 分为身份、导航偏好、实体查询缓存、草稿、pending operations，不能把余额作为可自由修改业务状态。读请求在返回前检查响应是否仍属于当前context，避免慢请求覆盖切家庭后的页面。401刷新合并为一次；刷新令牌轮换失败不能并发拿旧token不断刷。

上传器每图独立状态：SELECTED→UPLOADING→PROCESSING→READY，失败进入FAILED；支持移除与重试，选图取消保留已有内容。上传URL过期重新取新上传意图，不用旧对象ID假定成功。结束上传调用finish后轮询处理状态（退避1/2/4/8秒，前台最多30秒后显示可稍后回来）；回到前台重新查。后台挂起不保证回调，状态必须可由服务端恢复。所有所选图片READY前禁用提交，并说明是哪张未就绪；移除失败照片后可无图提交。

提交按钮同步锁定本地意图并显示处理中。超时进入“结果确认中”，查原key；发现成功定位原订单/提交，不再弹新确认单。如果NOT_OBSERVED则同key同请求重试，用户改内容前先解决原意图。返回新余额后刷新首页、账本、订单和心愿，不能只改卡片上的数字。

本地草稿按实例隔离；显式“保存草稿”才写服务器。照片尚未关联提交只有24h保留，旧草稿图片已清理时显示重新选择；不能把昨天照片自动关联今天。UI从前台恢复、下拉刷新、关键操作成功或冲突时刷新时间/状态。倒计时仅展示，服务端截止校验决定成败。

## 7. 后端实现、部署与运行目标

### 7.1 数据与事务实现

所有账务按05的统一锁序和双delta表。媒体在ActivityOccurrence之后、RedemptionOrder之前锁，同类UUID排序；绑定事务在家庭权限门内依次锁邀请、申请、目标孩子/FamilyPrincipal，同账号不同家庭的多行按UUID顺序。关系写入与撤销会话使用门锁和版本，使撤销后新请求/媒体读取拒绝。

部分唯一索引、同家庭复合外键、角色互斥FamilyPrincipal、计划区间不重叠、不可变流水权限均需SQL migration；不能只依赖应用层校验。数据库层CHECK只检查本行范围，跨表守恒在事务与对账中执行。[PostgreSQL 官方约束说明](https://www.postgresql.org/docs/current/ddl-constraints.html)

事务回调内不调用微信、媒体处理或外部存储。写操作保存outbox与业务同提交；worker按租约分批处理，事件键去重。过期扫描每分钟、对账每日、媒体未关联清理每小时、180d证据清理每日、导出/删除任务持续轮询；漏跑可补扫，任务不得以“已扫描到此时间”跳过仍未处理行。

关键伪代码：

```text
approveOrder(actor, orderId, expectedVersion, key):
  transaction:
    verify live session + profile + family permission under gate locks
    claim idempotency scope/key; replay if committed
    lock order; verify version and PENDING_APPROVAL
    read actual server time after lock
    if now >= approvalExpiresAt:
      expire with release + stock restore + original-week quota release
      save expired outcome; commit
    else:
      lock child account in global lock order
      heldPoints -= original cost; account.version += 1
      append ORDER_CAPTURE(availableDelta=0, heldDelta=-cost)
      order = READY; append audit/outbox; save response; commit
```

只读事务对账用一致快照，异常不得直接覆盖余额。修复工具接受唯一 repairId、原因、受影响业务ID、复核身份，先dry-run输出差异，再受审计执行；生产账务修复需要运行手册授权。此处约束后续运维，本次不执行生产操作。

### 7.2 构建与发布顺序

1. 锁依赖、静态检查、类型检查、领域单元测试；OpenAPI生成与客户端类型差异检查。
2. 在真实PostgreSQL跑migration、事务/约束/并发/隔离测试；媒体处理在隔离fixture上验证EXIF清理和大小限制。
3. 构建API/worker镜像与微信小程序产物，记录commit、配置环境和migration版本；扫描产物无secret及mock登录入口。
4. 测试环境微信真机登录、头像昵称门、DIRECT绑定、DELEGATED/PIN、照片流程、订阅拒绝不影响主流程；核对服务器域名与隐私声明。
5. 生产先备份，部署向后兼容migration，再API/worker，再体验版真机验收，最后小程序提审发布。小程序审核是外部步骤，不假设提交立即上线。
6. 观测错误、过期堆积和对账；应用回滚只退到兼容数据库版本。不可逆migration另出恢复方案，不默认执行清库/降级。

### 7.3 非功能验收基线

以下均为目标，不是现有测试结果。首轮基准数据：1,000家庭，每家庭2家长/3孩子、每孩子20日常计划、180天历史、每孩子500笔积分流水、100订单；90%读/10%写，50并发在线会话，稳定100请求/秒持续15分钟，其中至少10并发竞争同一奖励库存/孩子账户。记录实际实例规格、数据库配置、网络、请求分布和采样，压测环境不含真实孩子数据。

| 项目 | 首发验收目标 |
|---|---|
| 一般API | 读p95≤500ms，写p95≤800ms，不含微信登录与图片传输/处理；5xx<0.5% |
| 并发正确性 | 重复/竞争场景无重复发奖、超卖、负A/H、错误额度、跨家庭写入 |
| 上传处理 | 合法≤10MiB图片上传完成后处理p95≤10秒（20并发处理任务，给出CPU/内存），失败可恢复 |
| 任务延迟 | 正常服务状态下72h到期的释放99%在到期后2分钟内完成；超时仍拒绝批准并如实显示处理中 |
| 权限撤销 | 撤销提交后发起的新业务请求和媒体代理读取立即拒绝；已下载内容不承诺收回 |
| 数据恢复 | RPO≤15分钟，RTO≤4小时；必须实演验证购买配置 |
| 可用性 | 月度核心服务99.5%为首发目标，外部微信失败独立统计，计划维护另记 |
| 手机体验 | 按02/03规定360–430px、字体、键盘、安全区与弱网完成任务；图片不堵塞无图提交路径 |

监控：请求延迟/5xx、登录失败、PIN限流、媒体处理失败与队列年龄、到期待释放数量及最长超时、outbox重试、数据库锁等待/死锁、幂等冲突、对账差异、隐私申请临期/超期。日志用requestId串联，无自由文本或秘密。积分对账不平与越权事件立即告警；过期队列超过5分钟、导出超过24h、删除将达期限需值班人员处理。

移除成人、解绑孩子、PIN重置与删除写入独立加密恢复保护日志，成功回执前确认该日志持久化；数据库已提交但日志尚未确认则动作结果保持待确认并由outbox补齐，不能宣布完整恢复保障；OperationRecord标protectionBarrier=PENDING，查询/同key重试/缓存重放一律等待独立日志receipt后才返回最终成功，不得绕过该门。外部日志写在业务事务提交后，普通账务事务内不等外部网络。恢复时先回放最新安全版本/撤权/删除清单并撤销所有旧会话，无法确认最新权限的家庭默认关闭访问，独立核对后才开放，避免旧成员重新微信登录获得已撤销关系。

备份每日全量+持续WAL/PITR，保留35天；存储加密且恢复权限分离。上线前和每季度在隔离环境恢复，校验业务事实、账本、库存、会话撤销、幂等结果、媒体引用以及删除标记，出具恢复耗时和数据损失测量。不能只报告“备份任务绿灯”。

## 8. 隐私导出删除与账号支持运行手册

这是本产品拟定的服务处理方案，正式上线须将同样内容写入用户隐私说明、配置真实处理人员及联系渠道，并以实际运行结果验收。归档不等于删除，P0不能只有一个通向空白页的按钮。

### 8.1 申请资格与状态

家庭全量导出/删除仅当前OWNER，使用短时step-up和具体范围确认。账号本人（含DIRECT）可申请个人数据导出/删除，DELEGATED不能申请源家长账号数据。本人账号有任何家庭OWNER关系时，每个相关家庭必须先完成以下一条路径：转让给另一位有效家长；或归档、申请家庭删除并完成家庭在线主数据删除后，再完成个人账号删除。仅归档而仍保留家庭不满足条件，此时个人删除申请保持NEEDS_ACTION并提示具体下一步，不能留下无主的只读家庭。家庭删除先归档并清空待处理完成/订单，显示非零账本将被清理的明确范围。

状态 `RECEIVED → VERIFYING → PROCESSING → COMPLETED`，允许 `NEEDS_ACTION / REJECTED / FAILED_RETRYABLE`；每条有requestedAt、dueAt、当前负责人、对用户可见说明和审计。RECEIVED即返回申请ID；自动校验可当场完成，需人工事项1个工作日内受理并说明下一步，不用内部状态冒充完成。

### 8.2 导出处理

通常24小时内生成，最多3个自然日；预计延迟需在dueAt前给出原因和新处理时间，不能悄悄延期。家庭包包含家庭/孩子资料、计划与版本、完成/审核、积分流水、奖励/订单、业务审计，以及仍在180天期限内且有权访问的完成照片。导出附schemaVersion、生成时刻、时区、记录数、文件清单及校验和，CSV UTF-8与JSON并存；不同实体保持可连接ID。

个人包只含本人账号资料、本人关系摘要、本人所绑定孩子有权范围和本人操作，排除其他孩子/成人私有账号字段；不包含openid、PIN哈希、恢复码、token、内部安全日志。导出对象私有，生成后7天删除；每次下载通过鉴权代理、60秒grant和当前关系重验。家庭权限已被撤销则不能下载旧家庭包。

### 8.3 删除处理

确认有效申请后，7个自然日内完成在线主库及在线媒体/缓存/导出副本的删除或不可逆去标识化，并在申请中列明已完成范围。家庭删除清理孩子昵称头像、完成文本/照片、奖励/计划、账本、订单与幂等响应；不永久保留可重新识别孩子的完整流水副本。仅保留最少申请回执与删除标记用于证明处理与防恢复，限制访问并设期限。

个人账号删除撤销所有会话、解绑自己的DIRECT关系、删除账号身份及头像；家庭共同业务事实是否随之删除取决于其数据主体/共享范围，先出具范围清单，不自动删除他人的家庭。对于需保留以解释其他成员既有账务的操作事实，去除可识别的账号关联和资料，只留“已删除账号”操作者及业务金额/时刻；涉及该孩子本人敏感媒体和文本的部分按确认范围清理。需要负责人处理的部分转NEEDS_ACTION并解释，不能静默把个人删除等同于全家删除。

备份最多35天轮换清除，不供日常查询；在此期间若灾难恢复，必须先重放删除标记，再恢复对外服务。最迟在线删除完成后35天检查备份覆盖并完成最终回执。删除标记只保存不可逆散列/最少资源定位，备份轮换确认后30天清除。确有必须延后处理的外部约束时，需明确范围、依据、期限和限制访问措施，不用泛化“合规需要”永久保留全部数据。

### 8.4 PIN恢复支持

有一次性恢复码：验证新的微信身份与恢复码，重设PIN，轮换恢复码、递增securityVersion、撤销全部旧会话；不能仅微信身份即自动重置。新码展示响应丢失时按同recoveryAttemptId在短时安全窗口恢复；超窗且新码也未保管则转支持。

无PIN且无恢复码：1个工作日内受理支持申请，3个自然日内给出能否处理或所需补充说明。支持人员只能按预先批准的独立证据方案验证，不能将同设备、知道孩子昵称、静默微信登录视为充分证明；缺少足够证据就告知无法重置并保持锁定，不设延时自动解锁。工单不得收集不必要的孩子证件/学校地址，也不在聊天/日志回显恢复码。重置只能由受审计工具执行，记录工单与复核人，不手工改数据库哈希。

## 9. 测试、实施交付与旧数据

测试不能只用Mock数据库。首发必须提供：

- 规则单元测试：日期边界、版本选择、目标单位、状态迁移、A/H双delta、新发分上限和超限退款、周归属。
- 数据库集成：所有约束、事务回滚、同幂等重放/不同内容冲突、重复审核恰一次发奖、最后库存竞争、取消与兑现/批准与到期竞争、撤销足额与重复。
- 身份隔离：未登录/PROFILE_ONLY不能业务；无READY头像不能过资料门；DIRECT不能改成家长，DELEGATED不能读取源User资料；重新wx.login不能绕PIN；另一家庭合法家长上下文仍须本账号PIN；解绑/移除/归档后新读写/媒体读取立即拒绝。
- 照片：伪MIME、超10MiB/40MP、畸形图、EXIF/GPS清理、512/1600尺寸、处理失败重试、跨家庭/孩子/实例媒体ID、超过3张、非READY提交、退回新版本保留、24h/180d清理、已下载图片边界。
- 微信真机：首次登录和强制资料、取消拍照/相册权限、重复进入、DIRECT绑定、DELEGATED退出、弱网提交后杀进程恢复、上传期间后台挂起、长文案与安全区。
- 运维验收：真实备份恢复与对账、到期worker停机后补扫、outbox重复投递、导出权限撤销、删除主库/媒体/备份恢复重删、PIN支持无证据不重置。

交付清单：可运行源码和lockfile、schema与SQL migrations、OpenAPI完整参数/响应/错误码、环境配置模板、测试报告和并发数据、真机录屏、媒体处理/权限说明、部署与回滚手册、备份恢复演练记录、对账修复工具、导出/删除操作手册和指定值班联系人。按 [07-验收与实施交接](07-验收与实施交接.md) 逐项签收。

外部数据导入需明确身份映射、原余额、待兑现权益和来源凭证，经人工确认、试导入及数量和余额对账后切换。不能从成人账号推断孩子，不能把已扣款订单当作待批准申请再次预留积分。禁止以生产清库或强制重置代替迁移。
