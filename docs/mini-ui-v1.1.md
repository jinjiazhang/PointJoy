# 积乐圈小程序 · v1.1.2 界面实现说明

本次在现有 **uni-app / Vue 3 / TypeScript / Pinia** 前端上统一更新界面，继续使用真实业务数据、既有接口与权限校验。`pages.json` 保留 **32 条页面路由**：账号与共享页面 8 页、家长页面 17 页、孩子页面 7 页，覆盖登录资料、家庭与成员、活动计划、完成审核、奖励兑换、积分记录、成长、隐私及操作恢复。

采用用户指定的 **iOS 27 启发风格**，参考 Apple 的 [Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 与 [Liquid Glass](https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass) 材质方向，通过小程序 CSS/WXSS 实现：1.1.2 顶部保留玻璃质感，改为紧凑单行导航；底部延续 1.1.1 的全宽白底、贴底固定标签栏，顶部细分隔线，不设外边距、圆角或阴影，选中图标与文字使用蓝色。正文继续使用白色或接近不透明的内容卡片；浅灰背景 `#F5F6FA`、深色正文 `#1C1C1E` 和系统蓝 `#007AFF` 建立层次。蓝紫、薄荷渐变与柔和阴影作为内容区的低干扰装饰，配合清晰的内容标题、圆角分组和统一图标。顶部模糊效果取决于终端支持，内容与操作不依赖模糊效果才能辨认。

- **导航与页面。** 去掉独立的“积乐圈”品牌行以及正文重复的家庭名称和页面大标题。家长主标签顶部同一行显示“家庭名称 ▾ + 当前页面短标题”，点击家庭名切换家庭；详情、表单等页面显示返回图标与短标题。孩子主标签同一行显示“家长入口”或“我的账号”与标题：共用设备通过 PIN 验证退出，独立账号进入本人账号。现有孩子 API 不提供家庭名称，因此不额外读取家长内容或扩大权限。长家庭名省略显示，顶部为微信胶囊预留空间。家长底部为「首页 / 计划 / 奖励 / 家庭」，孩子为「今天 / 心愿 / 成长」；标签栏白底延续至底部安全区，正文预留其占用高度。家庭首页仍展示真实日常进度、三类待办、孩子积分和进度卡，计划编辑和完成审核保留既有分组与流程。

- **头像、昵称与照片。** 保留微信登录后的必填头像、昵称与隐私同意流程，支持选择微信头像、微信昵称推荐以及相册或拍照选择头像。头像选好后自动保存，无需用户重复点击上传；临时图片仍经后台处理并保存为私有媒体。完成照片保持选填，最多 3 张，支持预览、保存状态、失败重试和移除；仅全部已选照片就绪后才能提交。草稿照片自上传保留 24 小时，完成照片自首次正式提交保留 180 天；已使用头像不套用该清理期限。

- **兑换与反馈。** 兑换申请采用底部确认浮层（bottom sheet），列明本次积分、申请后可用与预留余额，并说明批准后扣除、72 小时未批准自动释放。批准、拒绝、取消与兑现也使用明确的操作说明；兑现仅用于实际提供完整奖励后确认。提交中按钮防重复操作，失败原因显示在浮层内；全局保留加载、空状态、读取重试及网络结果未明时查询原操作的入口。

- **业务与安全边界。** 活动补记、草稿、审核、暂停／停止、奖励库存与限额、积分账本及归档只读规则继续沿用既有实现。私有媒体仍经过权限校验和短时访问授权，孩子只能查看自己的授权内容；头像选择不会改变媒体权限。生产 API 仍为 `https://pointjoy.jinjiazh.com/api/v1`，本次界面调整不改变后端业务契约。

实现入口为 `apps/mini/src/design/theme.scss`、`components/AppShell.vue`、`AppIcon.vue`、`MediaUploader.vue` 及各 `features/*Screen.vue`。本文记录代码中的实现范围，不作为微信体验版上传成功或真机验收完成的证明；具体构建、上传和设备验证结果应以对应发布记录为准。
