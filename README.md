# 积乐圈 · PointJoy

可运行的第一版，2026-09-15。使用 uni-app + Vue 3 + TypeScript + Pinia、NestJS、Prisma、PostgreSQL。页面支持手机和桌面宽度，H5 与微信小程序使用同一套前端源码。

## 直接体验

本机运行中时打开 **http://127.0.0.1:5178**。选择「林小满」，再选择「周末成长小队」。

| 演示身份 | 适合体验 |
|---|---|
| 林小满 | 周末成长小队群主、读书充电站成员、一起动起来管理员；直接比较三种角色 |
| 陈一诺 | 周末成长小队管理员、读书充电站群主；可以为林小满发分和核销 |
| 周予安 | 周末成长小队成员、一起动起来群主 |
| 许星河 | 初始没有群组，可体验创建群及邀请码加入 |

所有数据保存在专用 PostgreSQL Docker 卷中，刷新页面和重启服务不会清空。种子脚本只初始化空库，重复运行保留现有数据。

## 本地启动

环境：Node.js 22 或更新版本、npm、运行中的 Docker。已在 Node.js 24.10.0 和 PostgreSQL 16 上验证。

Mac 可双击 [启动积乐圈.command](启动积乐圈.command)，或在项目目录执行：

```sh
npm ci --cache work/npm-cache
npm run setup
npm run dev
```

`setup` 仅在缺少 `.env` 时生成本地配置和随机加密密钥，然后创建专用数据库容器、生成 Prisma Client、执行迁移及初始化演示数据。请保留 `.env` 中的 OPERATION_KEY，已有幂等结果需要原密钥解密。

- 浏览器：`http://127.0.0.1:5178`
- API：`http://127.0.0.1:4100/api/v1`
- 数据库：`127.0.0.1:55432`，数据库名 `pointjoy`
- 健康检查：`GET /api/v1/health`
- 停止前后端：运行终端中按 Ctrl+C；停止数据库：`docker compose stop`。停止保留数据，不要使用 `down -v` 清除卷。

## 已实现的功能

- 一个用户创建、加入多个群，切群后独立加载角色、积分、奖励和订单；按用户记住最近选择。
- 群资料修改；群主授予/撤销管理员和转让群主。
- 生成 7 天有效的邀请码、申请加入、管理员审核。邀请码哈希保存。
- 对他人发积分、正负调整、原记录单次冲正；不能自发分或产生负余额。
- 奖励草稿、新建/编辑、上下架、有限库存增减、六种内置封面。
- 一次兑换一份奖励，事务内创建订单、扣分、扣库存、追加双流水。
- 待领取订单取消后自动全额返分和恢复库存；管理员填写交付备注后人工核销，不能核销自己订单。
- 本人积分明细、兑换记录，管理员成员详情、待审批和管理操作记录。
- 幂等键防重复执行；结果不确定时保留原请求重试，刷新页面也可恢复待确认请求。
- 数据库同群复合外键、余额及库存检查、订单状态检查、只追加流水保护和幂等响应 AES-GCM 加密。

## 这一版的明确边界

这是一版本地功能验证应用，尚未发布到微信，也不是可直接公网部署的商业版本。

- 登录使用演示会话，未实现微信 code 登录、刷新 token、账号资料编辑及用户禁用管理。`DEMO_AUTH=true` 仅允许本机监听，生产模式启动会拒绝。
- 图片使用内置 SVG 封面及已生成的品牌图标；COS 上传、图片校验尚未接入。
- 虚拟权益及实物均走人工交付；此次实现管理员从订单列表核销，未实现短时核销码、扫码、快递及第三方发券。
- 邀请目前通过手工邀请码加入，未实现微信分享参数、邀请撤销和申请撤回。
- 页面汇总接口 `/groups/{g}/dashboard` 为本版增加，个人流水和订单最近 100 条、管理审计最近 50 条。历史读取接口支持游标分页；页面暂未增加“加载更多”。群和奖励列表未为大规模数据优化。
- 为快速联调，接口成功统一返回 HTTP 200；分页 cursor 暂用资源 UUID；人工核销入参暂为 `{reason}`，与设计文档的 `{method,note}` 有差异。其他读接口使用本文代码契约；后续应生成正式 OpenAPI 并补齐设计稿协议。
- 自动对账调度、通知 outbox、生产备份、监控和部署尚未配置；测试中验证了账户及库存对账。
- 已升级 NestJS 和可兼容的 Vite 补丁。uni-app 模板及部分构建工具依赖仍有 npm audit 告警；上线前需进一步升级和评估依赖链，不应将本地开发服务暴露到公网。

## 微信小程序产物

```sh
npm run build:mp-weixin -w apps/mini
```

输出目录：`apps/mini/dist/build/mp-weixin`。可以在微信开发者工具中导入。当前 manifest 的 AppID 留空，需配置自己的 AppID；请求地址为本机 API，仅用于开发者工具模拟器。真机及正式版需要部署 HTTPS 后端、配置合法域名并替换演示登录。

已验证小程序编译成功；尚未进行微信开发者工具或真机运行测试。H5 浏览器已实测。生产配置应开启域名校验。

## 验证命令

```sh
npm run check
```

包括后端 TypeScript 编译、H5 构建、微信小程序构建、前端类型检查及真实 PostgreSQL 集成测试。测试自动创建随机命名的独立测试数据库，使用 4101 端口，结束后删除本次创建的测试库，不修改预览数据。

13 项业务场景覆盖多群、越权、自发分、重复兑换、幂等键冲突、取消返分、不可修改流水、库存竞争、余额不足回滚、改价冲突、跨群兑换、核销取消竞争、角色版本、冲正及总账核对（部分场景合并在同一测试中）。
